# Bili-Bill

**Bili-Bill 0.13.0-alpha（内测版本）**

Bili-Bill 是一个 Chrome/Edge 扩展，用于长期归档 B站观看历史，并把跨设备历史记录和本机网页播放行为合成为个人内容账单与分析面板。
同时提供智能收藏夹能力：在不改动 B站原收藏夹的前提下，同步收藏视频元数据，生成 AI 分类树，并支持自然语言找回收藏内容。
0.13.0-alpha 当前范围包括内容账单、固定三栏动态账单、智能收藏、四类视频盲盒、当前视频 AI 助手、字幕查看与本地问答会话，以及统一的 AI 与本地数据设置。

动态账单面向「兴趣再平衡」，固定展示“被淹没的关注、收藏关联更新、关注轮换”。它只依据当前可用证据解释入选原因，不做个性化推荐或点击概率排序。

## 当前能力

- 使用 B站历史接口 `/x/web-interface/history/cursor` 作为跨设备主数据源，覆盖 PC、手机、平板等历史记录。
- 使用本机网页 `playerEvents` 作为 PC 实测增强，修正本机观看时长、连续观看天数和设备分布。
- IndexedDB 长期保存历史记录，不依赖每次临时读取接口。
- 支持全量同步、增量同步、同步进度显示、同步取消和本次同步数量上限。
- Popup 改为独立持久小窗，点击扩展图标会打开或聚焦窗口，不会失焦自动关闭。
- 面板展示自然周、自然月统计范围、命中记录数、本地历史覆盖范围和设备分布。
- 面板展示当前连续观看时间段和历史最长连续观看时间段。
- 智能收藏支持同步 B站收藏夹、AI 分类树、分类下钻、自然语言搜索和基于本地索引的引用式问答；不会改动 B站原收藏夹。
- 当前视频助手包含“摘要、亮点、问答、字幕”四个页签。摘要与亮点由当前分 P 的完整主要文本生成；问答先给答案，再列可核对引用。
- B站字幕正文可查看、搜索并导出 TXT/SRT。B站 AI 字幕尚未进入播放器时，需要用户先在播放器中手动开启中文 AI 字幕，再重新检测。
- 视频亮点的时间范围只从当前主要文本的真实时间行派生；跳转必须经过预览和确认，并支持返回原播放位置。
- 问答会话保存在本地，可在切换视频后继续使用；每次新问题只绑定提交时的当前视频、分 P 和完整主要文本版本。
- 动态账单固定为三栏兴趣再平衡，并支持少提醒、30 天暂停、撤销、恢复与一次性低压力取关提示；不会自动修改关注关系。
- 视频盲盒固定为“随机探索、跨区漫游、冷门收藏、UP 主考古”，每张卡明确候选来源和是否使用真实 B站候选。
- 设置页统一管理当前视频、智能收藏与动态账单 AI 开关，以及本地数据状态、分类清理、全部清理和诊断导出。
- 支持 JSON/CSV 导出本地历史数据。

## 数据口径

- 本周：周一 00:00 到今天当前可用数据。
- 本月：当月 1 日 00:00 到今天当前可用数据。
- B站历史记录中的 `progress` 是跨设备估算字段，不等同于真实播放时长。
- 本机 PC 播放时长来自扩展运行后的播放器心跳和播放事件。
- 同日同视频同时存在 B站历史记录和本机 PC 事件时，优先使用本机实测，避免重复计数。
- 连续观看天数同时参考 B站历史记录和本机 PC 有效播放日期；当前连续和最长连续都会展示真实起止日期。
- 智能收藏夹只使用收藏视频元数据（标题、简介、UP 主、原收藏夹等）进行 AI 分类和检索，不下载视频、不分析画面、不写回 B站收藏夹。

## 同步机制

- 首次同步或手动刷新：从 cursor 首页开始翻页归档，最多可选 10/50/100/300 页，约 300/1500/3000/9000 条。
- 日常后台同步：每 5 分钟执行增量同步，遇到本地已有边界记录后停止。
- 去重键：`sessionKey = kid:viewAt`，兼容同一视频多天重复观看。
- 同步锁：防止重复点击造成并发写库；异常锁会按超时和 Service Worker 重启检测策略自动清理。
- 停止同步：点击停止会设置取消标记并 abort 当前网络请求，视频详情补全、限流等待、重试等待和页间等待也会尽快中断。

## 智能收藏夹

- 在面板的“智能收藏”页使用。
- 点击“同步收藏夹”会读取当前 B站登录账号的收藏夹列表和收藏视频，以完整快照保存到本地 IndexedDB；B站端已删除或移出的收藏会从本地同步清理。
- 在“AI 配置”中填写 OpenAI 兼容接口参数，默认适配 DeepSeek：`https://api.deepseek.com` 和 `deepseek-v4-flash`。
- 保存自定义 AI Base URL 时，扩展会申请对应 host 访问权限；用户拒绝授权时不会保存不可用配置。
- 点击“生成智能索引”会分批生成分类路径、摘要、关键词和可检索别名；当前每批处理 8 条，降低 MV3 Service Worker 长任务中断风险。
- 顶部统计会区分收藏视频、索引成功、索引失败和待索引；失败项再次生成索引会按失败队列重试一轮。
- 分类树支持展开/收起，点击分类名称会在右侧展示该分类及子分类下的视频。
- 搜索框支持模糊描述，例如“苏德战争 库尔斯克”；结果卡片可跳转到对应 B站视频。
- 智能收藏夹不会创建、移动、删除或重命名 B站原收藏夹。

## 安装与构建

### 直接体验 GitHub Release

当 [Releases](https://github.com/LittleNuB/BiliBili-DataViz-Plugin/releases) 页面出现 `v0.13.0-alpha` 后：

1. 下载 `bili-bill-0.13.0-alpha.zip`。
2. 解压到单独目录。
3. 在 Chrome/Edge 的扩展管理页打开“开发者模式”，点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的解压目录。

GitHub 的“Code -> Download ZIP”下载的是源码，不包含构建产物 `dist/`。要从源码加载，请先完成下面的本地构建。

### 从源码构建

```bash
npm ci
npm run build
```

安装版本约定：当前 npm/package 元数据版本为 `0.13.0-alpha`；Chrome MV3 Manifest 内置 `version: 0.13.0`，通过 `version_name: 0.13.0-alpha` 暴露预发布标识。

然后在 Chrome/Edge 打开 `chrome://extensions`：

1. 打开“开发者模式”。
2. 点击“加载已解压的扩展程序”。
3. 选择项目的 `dist/` 目录。
4. 更新代码后需要重新运行 `npm run build`，并在扩展管理页点击“重新加载”。

## 隐私边界（本版本）

- Bili-Bill 不会上传完整历史记录、完整收藏列表、完整关注列表、Cookie、API Key、用户账号标识、个人资料或反馈记录到任何第三方。
- Bili-Bill 不会读取本地 Cookie 文件、key 文件、浏览器 profile 文件或 B站登录态文件。
- 当前视频 AI 助手是唯一允许发送完整正文的功能：只有用户主动开启默认关闭的“当前视频 AI 助手”，并点击生成或提问后，才会把当前分 P 的完整主要文本发送到用户配置的 AI 服务。开启开关、打开页面、恢复会话或切换视频都不会自动发送正文。
- 动态账单与智能收藏使用各自最小化的任务上下文，不会因为当前视频完整文本授权而扩大范围；入选、排序、状态推进和负反馈仍由本地规则决定。
- 扩展不会写回 B站关注关系，不提供自动取关/批量改动关注设置的能力。
- 所有配置与问答会话默认保存在本地浏览器存储。API Key 只用于用户主动触发的请求，界面不会回显已保存的完整值。

## 使用方式

1. 先在同一个浏览器 Profile 登录 [B站](https://www.bilibili.com)。
2. 点击扩展图标，打开持久小窗。
3. 选择本次最多同步条数。
4. 点击刷新图标开始全量同步。
5. 同步过程中可查看页数、获取条数、新增/更新数量、当前步骤，也可以停止同步。
6. 点击“查看完整面板”打开完整面板。

```text

    ai/                  OpenAI 兼容模型调用
```

## 限制

- B站接口返回范围由 B站决定；“无限保存”指扩展会长期保存每次可获取到的历史。
- 默认配置会保留最近 90 天观看历史，旧数据会被后台清理任务删除；如需真正长期归档，应调整保留天数配置。
- 扩展安装前未采集到的本机 PC 心跳无法补回。
- 如果用户关闭 B站历史记录，或接口不返回更早数据，扩展无法凭空恢复。
- 0.13.0-alpha 不提供本地语音转录、画面理解、OCR、说话人分离或多视频全文综合问答；没有可读字幕正文时不会伪装生成完整视频结论。
- AI 能力依赖用户提供的 OpenAI 兼容 API Key；API Key 保存在本地 `chrome.storage.local`，使用共享浏览器设备时应自行评估风险。
- 本版本是 GitHub 预发布，不代表 Chrome Web Store 已审核或已上架。
