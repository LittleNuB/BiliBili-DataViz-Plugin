# Bili-Bill 0.13 集成 QA 矩阵

状态：待实现后执行。本文不授权发布、改版本、打 tag 或关闭 issue。

## 1. 通用环境

- 使用 clean integration worktree 和已构建的 unpacked extension。
- mock 用于确定性失败、空状态、版本变化和时间推进；真实 B 站公开视频用于身份、字幕、跳转和候选源 smoke。
- 真实页面验证只使用浏览器当前运行态，不读取 Cookie 文件、profile、登录状态文件或本地 Key 文件。
- 如果真实页面需要用户登录或手动开启 B 站 AI 字幕，由用户在浏览器中完成；QA 不提取或记录凭据。

## 2. 自动验证

- 全量 focused test scripts。
- `npm run typecheck`。
- `npm run build`。
- `git diff --check`。
- AI payload audit。
- 数据迁移 fixture：0.12 配置和 IndexedDB 升级到 0.13。
- 时间可控测试：30 天暂停、到期恢复和第 3 次有效少提醒。

## 4. 问答会话与跨视频连续使用

## 9. 文案与隐私扫描

扫描用户可见源文件和构建产物：

- 禁止状态文案：`未消费`。
- 禁止产品表述：`猜你喜欢`，除非出现在明确否定性测试 fixture 中。
- 禁止 raw 泄漏：`fallback`、`transcript`、`confidence`、`sourceHash`、`segmentId`、`subtitle_url`、`document is not defined`。
- 禁止敏感内容：完整 API Key、Cookie、profile 路径、登录状态、完整历史/收藏/关注/反馈、字幕或会话正文诊断导出。

扫描命中必须按“用户可见 / 内部实现 / 测试否定样例”分类，不能把内部合法字段直接当成 UI 泄漏，也不能用内部字段合法存在为 UI 命中开脱。
