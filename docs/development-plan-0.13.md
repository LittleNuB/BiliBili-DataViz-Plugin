## 2. 工作方式

- 每个实施切片使用独立 clean sibling worktree、`codex/` 分支和 draft PR 到 `main`。
- 子任务默认使用 `gpt-5.5 / xhigh`。
- 一个 issue 只实现一个切片，不把 PRD/spike、业务实现和发布操作混入同一 PR。
- 任何实现 PR 都不得修改 release、tag、package version 或发布资产。
- 不处理 #82/#83；只在最终集成 QA 时根据真实覆盖重新判断是否已被替代，且不得自动关闭。
- 不读取 Cookie/profile/login-state/key 文件，不读取 `C:\Users\LittleNub\Desktop\Key.txt`。
- 每个 PR 保持 draft/open，由主 Agent review 后再决定 ready、merge 和 issue 状态。

## 4. 实施切片

### DOC-013：0.13 单一合同

范围：

- 合并 grill 决策、术语、设置合同、技术 spike 和 QA 计划。
- 标记历史 PRD 的覆盖关系。
- 不改业务代码、版本、发布文件或 issue 状态。

完成条件：

- 0.13 实现只有一个明确的产品合同入口。
- 文档不存在互相冲突的现行规则。
- `git diff --check` 通过。

### SET-013-A：配置迁移与持久状态

范围：

- 把旧的当前视频摘要、片段重排和问答开关迁移为一个默认关闭的“当前视频 AI 助手”开关。
- 保留已有服务地址、模型名和有效 API Key，不根据旧开关扩大授权。
- 设置页切换、刷新和重新打开后显示真实持久状态。
- 保留智能收藏问答和动态账单解释开关；移除视频盲盒 AI 开关。
- 先定义共享本地数据类别注册合同：每类持久数据都必须提供数量/占用统计、独立清除、清除后回读和清理全部数据挂接接口。该切片只建立接口和注册规则，不新增功能数据表或设置入口。

不包含：

- 当前视频完整文本请求实现。
- 新增功能数据表或清理入口。

验收：

- 升级 fixture、保存失败、页面切换和重新加载测试。
- 测试连接 payload 审计。
- 设置 Browser/mock QA。

### CV-013-A：主要文本来源与完整文本授权边界

依赖：SET-013-A。

范围：

- 统一 B 站字幕正文、本地转录稿和当前主要文本来源状态。
- 区分“可能有 AI 字幕”“已探测轨道”“已取得正文”。
- 无正文时展示手动开启“中文 AI”字幕和重新检测入口。
- 定义完整文本请求 envelope、当前视频/分 P/文本版本身份和 payload audit。
- 固定主要文本身份字段及其在字幕正文、本地转录、摘要亮点缓存、问答轮次和清理操作中的绑定规则。
- 定义不可变请求快照和本地 `requestId`；问答额外使用稳定 `sessionId/turnId`，明确页面切换、取消、重试、清理和迟到响应的提交规则。
- 为当前视频正文数据类别交付 count/clear/readback hooks，清除后不得静默切换主要文本来源。
- 为 B 站字幕正文实现 50 个来源身份 / 50 MB 字节统计和最久未访问清理，并覆盖文字相同但时间轴变化的身份失效 fixture。
- 提升 Dexie schema，以完整字幕来源身份作为唯一键；0.12 旧字幕来源/行在 upgrade 事务中原子失效清除，其他类别不受影响。单个来源超过 50 MB 时只在当前页临时使用，不写入缓存。
- 打开页面、切换来源或开启授权时不发送请求。

不包含：

- 摘要、问答 UI。
- 本地 ASR 模型。

### CV-013-B：摘要与亮点合并生成

依赖：CV-013-A。

范围：

- 一次完整文本请求生成摘要、关键要点和亮点；模型生成内容并返回证据行，不生成时间，本地派生亮点真实时间与顺序。目标为 4-8 条亮点，较少但三部分非空且证据完整时仍可展示。
- 实现带本地文本行引用的结果 schema；每句摘要、每个要点和每条亮点都有可执行证据映射。
- 整体结构校验、本地证据时间派生、请求身份校验和全有或全无提交。
- 50 个分 P / 5 MB 本地缓存和主动刷新。
- 与缓存同时交付数据类别的 count/clear/readback hooks。
- 亮点预览、确认跳转和返回。

不包含：

- 字幕全文页。
- 问答会话。

### CV-013-C：字幕全文、搜索与导出

依赖：CV-013-A。

范围：

- “字幕”页签、B 站字幕/本地转录查看来源切换。
- 播放位置跟随、“回到当前字幕”、本地搜索和结果导航。
- TXT、SRT 导出。
- 查看来源与主要文本来源保持独立。

不包含：

- 本地转录执行。
- 翻译、编辑、外部字幕导入。

### CV-013-D：完整文本问答

依赖：CV-013-A、CV-013-B 的完整文本请求与结果校验基础。

范围：

- 每次问题发送当前分 P 完整主要文本。
- 先回答、后列 1-3 条引用。
- 实现答案段与引用都带内部文本行引用的问答结果 schema；校验引用文本、时间重叠、请求身份和全有或全无拒绝。
- 一次网络尝试只提交到匹配的 `requestId/turnId`；取消、重试替换或目标清理后的迟到响应丢弃。
- 上下文过长、取消、无文本和 AI 未配置状态。
- 引用预览、确认跳转和返回。

不包含：

- 会话持久化与跨视频连续使用。
- 多视频综合比较。

### CV-013-E：本地问答会话与跨视频连续使用

依赖：CV-013-D。

范围：

- 本地会话列表、标题、创建、切换、删除和 200 会话 / 25 MB 清理。
- 2000 中文字符滚动对话脉络和同一主要文本身份上一轮规则。
- 视频、分 P 或主要文本身份变化时清空模型侧脉络和上一轮内容；本地时间线保持连续，下一轮只使用当前参考视频。
- 每条回答的自然来源行、“在当前视频再问”和跨视频打开来源。
- 请求中切换页面、文本版本变化和失败重试的身份隔离。
- 同一会话最多一个活动请求；不同会话同文本并发和乱序返回依靠 `sessionId/turnId/requestId` 独立归属。
- 与会话持久化同时交付问答会话数据类别的 count/clear/readback hooks。

不包含：

- 多视频全文比较、云同步或全局问题模板。

### ASR-013-SPIKE：本地转录 go/no-go

依赖：DOC-013。Spike 复用仓库现有当前视频身份能力，并以 CV-013-A 的已确认合同作为目标，不等待正式改造完成。

范围：

- 严格执行 [`spike-local-transcription-0.13.md`](./spike-local-transcription-0.13.md)。
- 验证完整音频获取、offscreen/WASM、模型候选、固定样本、长视频和资源释放。
- 交付 spike 报告和唯一 go/no-go 结论。

限制：

- 不在普通 UI 开放实验入口。
- 不把原型代码混入正式功能 PR。
- no-go 不阻塞其他 0.13 切片。

### ASR-013-IMPL：本地转录正式集成

依赖：ASR-013-SPIKE 明确 go、CV-013-C。

范围：

- 只集成 spike 选定的一个运行时和一个模型。
- 模型下载、校验、缓存、取消、进度、完整稿预览和原子替换。
- 50 个分 P / 50 MB 转录稿缓存和独立模型清理。
- 与转录稿和模型持久化同时交付各自数据类别的 count/clear/readback hooks。
- 代表性样本与 90 分钟长视频门槛回归。

不存在 go 结论时不创建该实施 issue。

### DB-013-A：固定三栏与全局轮换

范围：

- 固定“被淹没的关注、收藏关联更新、关注轮换”。
- 移除长期历史统一前置门槛和旧栏目。
- 在任何动态账单公开读写 handler 访问表前调用同一迁移门禁，覆盖首屏账单/解释读取、反馈读写、状态更新、生成与同步写入、设置页统计。事务内使旧账单和解释失效、删除 topic feedback、把未到期 creator feedback 按 UP 归并为最多一条 30 天暂停，并写入 Dexie 迁移版本；旧次数不迁移。
- 迁移失败时所有入口返回同一自然中文升级失败状态且不暴露旧数据；迁移版本存在后，0.13 运行路径不再读取 legacy feedback 表。
- 关注记忆证据、收藏关系、唯一归属和每 UP 一项。
- 三栏共用全局轮换记录，每栏最多 5 项、总计最多 15 项。
- 单栏/全栏空状态和本地证据解释。
- 用 0.12 IndexedDB fixture 验证迁移中断恢复、重复启动和首次新账单生成前的状态。
- 覆盖升级后未生成即首屏读取，以及迁移完成后注入 legacy feedback 仍不影响候选、暂停或计数。
- 与新账单项和全局轮换记录同时交付动态账单数据类别的 count/clear/readback hooks。

不包含：

- 用户在 0.13 新执行“少提醒这个 UP”后产生的暂停、计数和取关提示交互；DB-013-A 只负责升级事务必须形成的未到期暂停。
- AI 决策或推荐排序。

### DB-013-B：状态、30 天暂停与一次性取关提示

依赖：DB-013-A。

范围：

- 保留未打开、已打开、已消费、已处理状态。
- “少提醒这个 UP”当前项转已处理、30 天全栏暂停、8 秒立即撤销和自动到期。
- 少提醒操作、撤销凭证、撤销截止时间、操作前账单项状态与操作前暂停状态持久化；过期后由后续读写原子 finalize，再进入有效次数。
- 第 3 次有效少提醒只在 finalize 后显示一次取关提示；撤销中的第 3 次不提示，刷新、重启或重复消息不重复提示。
- 本地暂停、计数和提示状态；设置页恢复接口。
- 只处理迁移后新的 30 天暂停、有效少提醒次数和一次性取关提示；不得再读取 legacy topic/creator feedback 作为筛选或计数依据。
- 与暂停和提示状态同时交付动态账单数据类别的 count/clear/readback hooks。

不包含：

- 插件内取关或写回 B 站。
- 主题级少提醒。

### BB-013-A：固定四类候选源

范围：

- 固定“随机探索、跨区漫游、冷门收藏、UP 主考古”。
- 每卡展示来源、入选原因和是否使用真实 B 站候选。
- 随机探索本地近期种子与真实相关候选。
- 跨区漫游复用固定公开分区目录和 `/x/web-interface/newlist` 候选源；按最近最多 7 天有效观看确定 top-3 高频 RID，无近期证据时等概率选择分区，并公开本轮分区。
- 2026-07-17 无 Cookie 复核确认旧 `/x/web-interface/dynamic/region` 返回 HTTP 200、`code=-404`、`data=null`，不得继续作为现行候选源；同日分别以 `rid=4` 和 `rid=36`、`pn=1&ps=10` 请求新接口，均返回 `code=0`、`data.archives=10`，首项均具有 `bvid/title/owner/duration/pubdate/tname`。
- 分区候选只读取 `data.archives`；缺少可打开视频身份或非空标题的条目不得入池。接口失败、空池或必要字段缺失时显示分区候选空态，不改用历史、收藏或其它盲盒来源。
- 无效 BVID、观看时间、时长、进度或完成度记录不参与跨区频率统计。
- 冷门收藏使用本地收藏，UP 主考古使用公开较早投稿。
- 候选模块保持浏览器运行时可加载，不能再次出现 `document is not defined`。

不包含：

- 去重记录。
- 推荐分或 AI 排序。

### BB-013-B：失败状态与最近 50 条去重

依赖：BB-013-A。

范围：

- 无种子、无真实候选、接口失败和不可打开候选状态。
- 禁止跨盲盒来源补位。
- 四类共用最近 50 个 BV 的本地最小去重。
- 全部候选已重复时允许从完整有效池抽取，不制造假空卡。
- raw 错误隔离和自然中文状态。
- 与抽取记录同时交付盲盒数据类别的 count/clear/readback hooks；clear hook 接入清理全部数据，但不新增单独设置按钮。

### SET-013-B：本地数据管理收口

依赖：CV-013-B/C/E、DB-013-B、BB-013-B；ASR 数据入口只在 ASR-013-IMPL 存在时接入。

范围：

- 展示各类数量、占用和最近时间。
- 分别清除字幕正文、摘要亮点、问答会话、本地转录稿和模型。
- 动态账单暂停列表与逐项恢复。
- 盲盒最近 50 条只显示计数，不增加独立开关。
- “清理全部本地数据”二次确认、实际计数回读和部分失败状态。
- 诊断导出边界。
- 只汇总各功能切片已经交付的数据类别 hooks；不得在该切片重新推导或直接耦合各模块表结构。

### QA-013：集成 QA 与旧 issue 审计

依赖：全部正式切片完成，ASR 有明确 go/no-go。

范围：

- 执行 [`qa-0.13-integration-matrix.md`](./qa-0.13-integration-matrix.md)。
- 真实页面与 mock 双轨验证，覆盖页面切换、刷新、失败和隐私边界。
- 执行用户可见文案和 raw 字段泄漏扫描。
- 只在证据明确时报告 #82/#83 是否被替代；不自动评论、关闭或改状态。
- 不修改 version、release、tag 或 package。

## 5. 每个实施 PR 的验证基线

- 与切片对应的 focused tests。
- `npm run typecheck`。
- `npm run build`。
- `git diff --check`。
- UI 切片的 Browser/mock QA。
- 用户可见代码扫描：`未消费|猜你喜欢`。
- 用户可见 raw 泄漏扫描：`fallback|transcript|confidence|sourceHash|segmentId|subtitle_url|document is not defined`。
- AI 切片的 payload audit。
- 明确回报未读取 Cookie、profile、login-state 和 key 文件。
