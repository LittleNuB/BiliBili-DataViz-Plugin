# Gate global full-text search before runtime implementation

Global search over managed full text cannot enter runtime implementation until both the deterministic synthetic-fixture foundation and the separately reviewed public-safe Bilibili-subtitle distribution calibration pass, followed by a Chrome MV3 feasibility gate at 100, 400, and 500 MiB. Synthetic fixture success alone does not establish representativeness. The gate compares at least an IndexedDB lexical-index approach and a proven chunk-persistable search library without making vectors or semantic indexing a release dependency, and measures build/resume time, peak memory, index size, Chinese and English query latency, cancellation, rebuild, and service-worker restart recovery. Failure returns capacity or search scope to product review; version 14 must not silently substitute metadata-only search, per-query scans over hundreds of MiB, or an unvalidated engine. [ADR 0089](./0089-split-synthetic-fixtures-from-measured-subtitle-calibration.md) records the original A1/A2 split; [ADR 0090](./0090-run-the-synthetic-storage-baseline-before-calibration.md) keeps calibration as a search-gate dependency while allowing the synthetic storage baseline to run earlier.
