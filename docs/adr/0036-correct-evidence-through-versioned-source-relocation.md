# Correct evidence through versioned source relocation

Knowledge-asset organization remains editable while captured evidence stays read-only. Correcting a source requires an explicit relocation flow over available complete text: the user chooses the target video and part, selects one continuous passage or time range, previews the exact source, and confirms. Confirmation creates a new active evidence version and retains the prior mapping as inactive “已更正” history; a multi-source asset changes only the selected citation. When exact complete text is unavailable, relocation is refused rather than approximated, and the user may obtain text first or separately create a personal note related to the selected whole video but carrying no evidence snapshot. This preserves correction ability without allowing ordinary editing to rewrite or erase historical support.
