# Ship the durable knowledge loop before cross-video AI

0.14.0-alpha ships a complete capture, retained-full-text, search, source-return, backup, restore, and clear loop without making new cross-video AI generation a release blocker. Single-input scope routing and source-bounded cross-video answers follow in 0.14.1-alpha, while vector retrieval, external MCP access, and arbitrary page clipping remain later validations; this isolates durable-data, capacity, and migration risk from multi-source model-call and citation risk.
