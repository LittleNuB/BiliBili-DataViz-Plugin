# Require separate knowledge-base AI authorization

Bili-Bill does not extend the existing current-video full-text permission to cross-video or personal-knowledge requests. Knowledge-base AI access starts disabled, can be granted once inline for the submitted question, remains active until revoked, and adds a separate warning only for materially large multi-source requests; granting or revoking it never uploads in the background or deletes local knowledge, prior answers, or local search data.
