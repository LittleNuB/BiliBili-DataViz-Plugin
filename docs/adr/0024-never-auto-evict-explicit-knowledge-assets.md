# Never automatically evict explicit knowledge assets

Notes, timestamp bookmarks, saved excerpts, and explicitly preserved generated results are user-owned durable knowledge and are never removed by automatic age, count, size, or least-recently-used cleanup. When a new durable save cannot be stored safely, Bili-Bill refuses that save and offers management or export rather than deleting older knowledge; rebuildable source text, generated caches, and indexes retain separate bounded lifecycles.
