# Bili-Bill 0.13.0-alpha 内测发布说明

发布日期：2026-08-01

`0.13.0-alpha` 是面向 GitHub 内测用户的已解压扩展预发布版。本轮把当前视频助手收束为可核对的完整工作流，同时重做动态账单和视频盲盒，使它们在 B 站只提供短期历史的现实条件下仍可使用。

本版本不是 Chrome Web Store 正式版。

## 本次重点

### 当前视频助手

- 助手固定提供“摘要、亮点、问答、字幕”四个页签，并绑定当前视频和当前分 P。
- 摘要与亮点由当前分 P 的完整主要文本生成。模型结果必须引用真实文本行；亮点时间范围由这些真实时间行在本地换算，不接受模型自报时间点。
- 模型可以返回较少但证据完整的摘要、要点和亮点，不再因为数量不足而整批拒绝；缺少证据、引用错位或内容超限时仍会安全失败并保留旧结果。
- 问答先显示回答，再列一至三条可核对引用。每次提问绑定提交时的当前视频、分 P 和文本版本，切换视频不会让迟到结果覆盖新页面。
- 问答会话保存在本地，可在之后回看视频时继续使用。跨视频继续会话时，新问题只使用提交当下的视频正文和紧凑的上一轮上下文；含糊的跨视频比较不会被强行猜测。
- 字幕页支持查看、搜索、跟随播放、TXT/SRT 导出和基于真实字幕时间的跳转。
- 所有时间跳转仍执行“预览 -> 用户确认 -> 跳转 -> 返回原位置”，不会自动改动播放位置。

### 动态账单

- 动态账单定位保持为“兴趣再平衡”，不承担个性化推荐或点击概率排序。
- 页面固定为“被淹没的关注、收藏关联更新、关注轮换”三栏，并以当前可获取的短历史作为默认事实边界。
- 支持“少提醒”、30 天暂停、撤销与设置页恢复。连续表达低兴趣后只提供一次低压力的手动取关入口，不会自动修改关注关系。
- 入选、归属、排序、状态推进和反馈处理均由本地规则决定；AI 只在用户开启后解释已经入选的单条内容。

### 视频盲盒

- 四类卡片固定为“随机探索、跨区漫游、冷门收藏、UP 主考古”。
- 随机探索和跨区漫游明确使用真实 B 站公开候选；冷门收藏只回访本地收藏；UP 主考古从近期观看过的 UP 主公开投稿中抽取较早内容。
- 每张卡都会说明候选来源和是否使用真实 B 站候选。
- 公开候选不可用、没有合格种子或视频不可打开时显示自然的降级状态，不再把本地库存冒充外部探索，也不会把运行时异常原文显示给用户。

### 设置、本地数据与隐私

- AI 服务配置、功能开关和本地数据管理集中在设置页；跨页面切换后开关显示与实际保存状态保持一致。
- 设置页可分别查看和清理历史、收藏、当前视频缓存、问答会话、动态账单和盲盒记录；全部清理需要中文确认并执行清理后读回校验。
- Manifest 不再申请未使用的 Cookie 权限。
- 当前视频 AI 助手是唯一允许发送完整正文的功能。只有用户主动开启该功能并点击生成或提问时，当前分 P 的完整主要文本才会发送到用户配置的 AI 服务；打开页面、恢复会话、切换视频或只开启开关都不会自动发送。
- 动态账单和智能收藏继续只发送各自任务所需的最小上下文，不会继承当前视频的完整正文授权。

### 发布可靠性

- 修复视频盲盒生产页面的运行时加载错误。
- 偏好页词云迁移到 ECharts 6 官方自定义系列实现，并增加桌面与移动端真实 canvas 像素检查。
- 新增 GitHub CI：全量测试、类型检查、生产构建、依赖审计和生产词云浏览器回归。
- 当前依赖审计结果为 0 个已知漏洞。
- 构建产物包含项目 MIT 许可证，以及 ECharts、d3.js 和 wordcloud2.js 的第三方许可与归属说明。

## 安装与升级

1. 在本 Release 下载 `bili-bill-0.13.0-alpha.zip` 和对应的 `.sha256` 文件。
2. 校验 ZIP 的 SHA-256 后解压；解压目录根部应直接包含 `manifest.json`。
3. 在 Chrome/Edge 的扩展管理页开启“开发者模式”。
4. 首次安装时选择“加载已解压的扩展程序”，并选择刚才的解压目录。
5. 从旧内测版升级前建议先导出本地数据。若希望保留同一个已解压扩展实例及其本地数据，应备份并更新原加载目录内容后点击“重新加载”；改用新路径加载可能形成新的扩展实例。

GitHub 的“Code -> Download ZIP”是源码包，不包含 `dist/`，不能直接作为已构建扩展加载。

## 已知限制

- B 站 AI 字幕需要先由用户在播放器中手动开启中文 AI 字幕，助手才能重新检测并读取正文。
- 本版本不提供本地语音转录、画面理解、OCR、说话人分离或多视频全文综合问答。
- 没有可读字幕正文时，助手不会把标题、简介或分 P 信息伪装成完整视频理解。
- 长视频会发送更大的完整文本，可能增加等待时间和模型费用；服务拒绝过长上下文时会显示受控提示，不展示服务原始错误。
- B 站接口可返回的历史和公开候选范围由 B 站决定，扩展不能补回安装前未采集的数据。
- 生产构建仍有一个已知的大体积图表 chunk 警告，不影响本轮功能与安装包验证，后续会单独处理代码拆分和包体优化。
- 自动化使用全新临时浏览器环境验证了公开页面、分 P 身份、扩展加载和无自动 AI 请求；真实账号字幕正文与用户自有 AI 服务的完整人工体验仍建议由用户在安装后完成。
